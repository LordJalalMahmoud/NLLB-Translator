# Meta NLLB-200 AI Translator 🌟 (المترجم العصبي فائق الجودة)

برنامج مترجم ذكاء اصطناعي عصري عالي الدقة يعمل **بدون إنترنت 100% (Offline)** ومبني على نموذج **Meta NLLB-200 (No Language Left Behind)** من شركة Meta (فيسبوك).

---

## 🌟 لماذا Meta NLLB-200؟

* **فهم عميق للسياق اللغوي:** يتفوق بمراحل على نماذج الترجمة التقليدية القديمة في فهم الضمائر والتراكيب البلاغية والقصصية.
* **شاشة مقارنة 4 في 1:**
  1. 🌟 **عربي فصحى حديثة (arb_Arab):** أعلى درجات الدقة والفصاحة.
  2. 🇪🇬 **لهجة مصرية عامية (arz_Arab):** ترجمة حوارية ممتعة وحية وممتازة لألعاب الفيديو!
  3. 💬 **فرانكو / عربيزي (Franco):** مشتقة مباشرة من مخرجات النموذج الفائقة.
  4. ⚖️ **مقارنة حية مع النموذج القديم:** يوضح الفارق بين الترجمة الذكية والترجمة الحرفية القديمة.
* **تكميم int8 سريع وخفيف:** يعمل على المعالجات العادية (CPU) بسرعة فائقة واستهلاك مناسب للرام.
* **أوفلاين 100%:** بعد التثبيت، يعمل البرنامج في وضع الطيران وبدون أي اتصال بالإنترنت.

---

## 🪟 طريقة التثبيت والتشغيل على ويندوز (Windows):

1. تأكد من تثبيت **[Python 3](https://www.python.org/downloads/)** مع تحديد خيار `Add Python to PATH`.
2. انقر نقراً مزدوجاً على ملف التثبيت التلقائي:
   👉 **`install_windows.bat`**
   *(يقوم بإنشاء البيئة وتثبيت الحزم وتنزيل نموذج NLLB لمرة واحدة فقط).*
3. للتشغيل:
   👉 انقر نقراً مزدوجاً على **`run_web.bat`** وسيفتح المتصفح تلقائياً على `http://127.0.0.1:8770`.

---

## 🐧 طريقة التثبيت والتشغيل على لينكس (Linux):

```bash
# 1. تثبيت المتطلبات
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 2. تنزيل النموذج لمرة واحدة
python3 download_model.py

# 3. تشغيل الخادم وواجهة الويب
./run.sh
```
ثم افتح المتصفح على:
👉 **`http://127.0.0.1:8770`**
